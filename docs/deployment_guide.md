# Deployment Guide

1. Replace repository placeholders with Dev environment values.
2. Deploy/configure Databricks notebooks.
3. Run Azure SQL serving-table DDL and indexes.
4. Create/configure ADF linked services securely.
5. Import/recreate ADF datasets and pipelines from the templates.
6. Test pipelines manually before enabling the schedule trigger.
7. Execute one complete run.
8. Reconcile Gold and Azure SQL counts.
9. Configure Power BI and publish only after validation.
